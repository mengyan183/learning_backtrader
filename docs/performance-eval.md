# 绩效评估规范（P6，回测方法论）

> 来源：知识库 QuantPy 频道 9 条量化回测沉淀 + Bailey & López de Prado
> 《The Deflated Sharpe Ratio》（2014）。本文是**回测/绩效评估的方法论契约**，
> 不代替策略信号；E3 回测文件恢复后按此规范校验。

## 1. 为什么需要规范

本地小模型与人工"看着不错"的回测都容易高估策略：
- **多重检验**：试了 N 个参数/变体，总有一个"显著"，其实是碰运气；
- **数据窥探**：用同一段数据既开发又验证，结果乐观偏误；
- **Sharpe 会骗人**：高 Sharpe 可能来自杠杆、尾部风险或样本选择，而非真实 alpha。

## 2. 必做检验清单（回测结果必须逐项出具）

| 检验 | 方法 | 通过标准 |
|---|---|---|
| **基准对比** | 与同口径基准（等权买入持有、SPY/QQQ）比净收益与回撤 | 年化超额收益 >0 且最大回撤不劣于基准 |
| **样本外检验** | 训练期/验证期按时间切分（如 7:3），只用验证期报告终值 | OOS 表现不显著劣于 IS（如 OOS/IS 比值 ≥0.5） |
| **Walk-Forward** | 滚动窗口：每 6-12 个月重拟合一次，累计 OOS 净值 | 累计 OOS 收益为正、回撤可控 |
| **Deflated Sharpe** | 见 §3：对多重检验做惩罚，给出调整后显著性 | PSR>0.95 才可称"统计显著" |
| **最大回撤压力** | 对照 scripts/mc_pressure_test.py 的 Monte Carlo 回撤分布 | 策略最大回撤不显著超过 MC P95 参考 |
| **敏感性** | 关键参数 ±20% 扰动后结果方向不变 | 结论不依赖单个参数取值 |
| **交易成本** | 计入佣金+滑点+借贷成本（杠杆 ETF 持有成本见 config.CRYPTO_LEVERAGE 注释） | 扣费后仍为正 |

## 3. Deflated Sharpe 公式（实现口径）

```
SR_obs   = 回测年化 Sharpe
N        = 尝试的策略/参数组合数
T        = 样本年数
E[max Z] ≈ (1-γ)·Φ⁻¹(1-1/N) + γ·Φ⁻¹(1-1/(N·e))
γ = 0.5772 (欧拉常数)
SR_deflated = SR_obs × √(1 - 4·κ4 + ... ) 简化口径：
PSR = Φ( (SR_obs - SR_0) × √(T-1) / √(1 - γ3·SR_obs + (γ4-1)/4·SR_obs²) )
```

简化落地规则（先跑起来，不追求精确实现）：
- 报告 SR 时必须同时报告 **N（试过的组合数）** 与 **T（样本年数）**；
- N ≥ 20 时，名义 SR < 1.0 一律不得宣称"显著"；
- 用 `scripts/backtest_check.py`（待 E3 恢复后建立）自动输出 PSR 与"是否通过"。
