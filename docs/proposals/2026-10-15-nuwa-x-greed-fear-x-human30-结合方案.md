**状态**：待 Windows 侧评审（本提案为方案稿，未落地任何代码）
**提出**：2026-10-15（Mac 端）
**关联**：`nuwa-skill`（`~/.openclaw/workspace/skills/`：`huashu-nuwa` / `munger-perspective` / `taleb-perspective` / `sun-yuchen-perspective`）；`docs/human30.md`；`docs/proposals/human30-ai-review.md`（H-REV-001，待 C-3）；`docs/trading-discipline.md`

## 1. 背景：三方能力与关系

| 系统 | 是什么 | 产出 |
|---|---|---|
| **贪恐系统** | 数据→指数→仓位目标→风控→简报/看板的确定性决策链 | fg_index/zone、target_position、P1 风控建议、每日简报 |
| **Human 3.0** | 个人状态自评系统（Level/象限 Archetype/相位/短板/窗口统计），AI 复盘提案 H-REV-001 待批 | `Data/human30.json`、页面状态卡、简报 🌱 板块 |
| **nuwa 视角 Skill** | 把人物/主题的**思维方式**蒸馏成可调用 SKILL.md（心智模型+决策启发式+表达DNA+反模式+诚实边界），Agent Skills 协议，OpenClaw 加载 | 对话式"思维顾问"（芒格/塔勒布/孙宇晨/…） |

**核心原则（贯穿全案）**：视角 Skill 是**思维顾问/研究参考**，**永远不进系统信号、不自动产生交易判决、不改变任何确定性规则输出**。它与贪恐系统的关系 = 人（决策者）在决策流程中的**审视辅助层**，不是信号层。

## 2. 结合架构

```
┌─ 视角 Skill 层（OpenClaw skills/）─────────────────────────┐
│  munger-perspective │ taleb-perspective │ sun-yuchen-perspective │ (myself) │
│  心智模型 + 决策启发式 + 表达DNA + 反模式 + 诚实边界            │

                │ 按需调用（仅用户触发/审批后的固定锚点） │
┌───────────────┴───────────────┐  ┌─────▼───────────────────────┐
│ 贪恐系统（确定性链，不可变）    │  │ Human 3.0（自评+复盘）        │
│ 检查单 / 简报 / 风控告警 / 持仓 │  │ 状态卡 / AI 复盘（H-REV-001） │
```

**边界红线**：所有结合点输出统一前缀 `🟡 思维顾问（研究参考，非系统信号）`；LLM/视角任何失败 → 静默降级为该处原有确定性输出，绝不阻塞主流程。

## 3. 接入点设计（按优先级排序）

### P0：交易前检查单注入「逆向审视」——`scripts/invest_research.py::behavior_checklist()`
- **现状**：检查单已有"集中优势兵力"等纪律项（human-in-the-loop，决策者逐条勾选）。
- **新增**：检查单末尾追加两项**可选**自问（默认折叠，不改变勾选流程）：
  - 「🔍 芒格审视：这笔交易**反过来看**，最大的错误会是什么？（逆向思考 / 认知偏误自查）」
  - 「🛡 塔勒布审视：最坏情景发生，我的损失是否在可承受范围？（尾部风险 / skin in the game）」
- **实现**：`behavior_checklist()` 输出追加两行文案（确定性模板，**不调 LLM**）；视角深度解读仅在用户明确点击"展开思维顾问"时通过对话触发（OpenClaw 侧）。
- **工作量**：极小（文案模板 2 行 + 页面折叠块）。

### P1：Human 3.0 AI 复盘支持视角注入（依赖 H-REV-001 获批）
- **现状**：H-REV-001（待 C-3）规划 `scripts/human30_review.py` 用本地 Ollama 生成 ≤200 字复盘。
- **新增**：获批落地时增加 `--perspective {none,munger,taleb,myself}` 参数：
  - 复盘 prompt 注入对应 SKILL.md 的心智模型段（如塔勒布：杠铃/黑天鹅/反脆弱视角解读自评数据波动）；
  - 输出仍 ≤200 字、仍带 `🟡` 前缀、仍固定模板（视角只改变解读框架，不改变边界）。
- **工作量**：中（H-REV-001 落地时顺带，读取视角 SKILL.md 的模型段拼接 prompt）。

### P2：简报/异动告警可选附加（默认关闭）
- 每日简报尾部、盘中异动告警尾部，可在**配置开关**（`config.py` 布尔）开启时附一行 `🟡 思维顾问：<一句话> `（由本地 Ollama 调用视角 SKILL.md 生成，失败即省略该行）。
- 默认关闭——避免简报膨胀与 LLM 成本。

### P3：human30 页面「视角」折叠卡
- Human 3.0 tab 状态卡尾部加折叠块：用户点开 → 通过 OpenClaw 对话调用视角 skill 解读当前状态卡（Level/短板/窗口统计 + 市场快照）。纯对话，无代码改动（OpenClaw 侧行为）。

| 层 | 提取什么 | 从哪来 |
|---|---|---|
| 怎么说话 | 表达习惯（简短/清单式/纪律口吻） | 消息/笔记/文档 |

| 知道局限 | 承认不确定（样本不足不下结论等惯例） | 研究纪律 |

### 4.3 生成路径（两步）

1. **材料聚合**：新增 `scripts/distill_self.py`——把上述本地素材聚合成调研集（结构化 txt/md），**只读**，不写系统状态。
2. **蒸馏**：用 `nuwa-skill/scripts/`（merge_research/quality_check）+ 本地 Ollama 按 `skill-template.md` 生成 `xingguo-perspective/SKILL.md`（骨架可先人工审，再让女娲补全）。

### 4.4 产物与用法

- `~/.openclaw/workspace/skills/xingguo-perspective/`（name: `xingguo-perspective`）
- 用法：**「用另一个我看看这个决策」「如果是我会怎么做」** → 复盘、决策审视、状态解读
- 与 human3.0 的闭环：human30 记录"我现在的状态"，myself 提供"我会怎么想"→ P1 的 `--perspective myself` 让**另一个我**解读我最近的 human30 状态（自我观察的镜像）。

### 4.5 隐私与纪律（硬约束）

- **素材不落外网**：调研集、SKILL.md 全部本地生成/本地存放；蒸馏用本地 Ollama（human30/llm.py 已有 Hermes/NVIDIA 双源，均走本地或自有密钥，按现有配置）；**不随 fg-sync 同步**（`xingguo-perspective/` 不在仓库白名单，仅 `~/.openclaw` 本地）。
- **不进交易链**：myself 输出一律 🟡 研究参考。
- **诚实边界**：SKILL.md 必须含"这是基于我的历史表达/决策的静态快照，不代表现在的我，更不是未来决策指令"。
