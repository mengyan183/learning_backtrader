## 3. 各任务修复说明

### WT-23 `markov.steady_state` —— 概率质量泄漏

**根因**：`transition_matrix` 对从未出现过的档位留下**全 0 行**（无出边）；
迭代 `pi @ P` 时落进这些行的概率质量被**漏掉** ⇒ 返回向量 sum < 1。

**实测（修复前）**：`zones=[0,0,1,1,2,2,2,1,0]` → **sum ≈ 0.6**；`P=zeros` → **全 0 向量**。

**修法**：零行补成**自环** `P[i,i]=1`（「进去就出不来」= 吸收态的标准处理，是唯一保持
概率守恒的解释）；返回前统一归一，并 `assert sum≈1` ✓。

**修复后**：`[0,0,1,1,2,2,2,1,0]` → sum = 1.000000 ✓；`P=zeros` → 均匀分布 ✓。

### WT-24 `evt._gpd_pwm` —— PWM 权重与公式双重错误

**根因**（两处 ✗）：
1. `w = i/(n+1)` 被**直接**乘在升序样本上 ⇒ 取到的是 `E[X·F(X)]` 而非
   `E[X·(1-F(X))]` ⇒ 指数样本 b1/b0 ≈ **0.75**（正确 0.25）；
2. 形状/尺度公式的分母写成 `(b0-b1)`，正确是 `(b0-2b1)`。

**实测（修复前）**：指数样本（真值 ξ=0, σ=1）被估成 **ξ ≈ -2.03、σ ≈ 6.15** ✗。
因 `pot_analyze` 里 ξ<0 与 `(-ξ)` **双重取负**，输出**看着仍合理** ⇒ **静默偏差**，
直接污染「20/80 边界校准建议」。

**修法**：改回 Hosking-Wallis 标准 PWM ——
`b0 = mean(x)`、`b1 = mean((1-p)·x)`（`p = i/(n+1)`），
`ξ = (b0-4·b1)/(b0-2·b1)`、`σ = 2·b0·b1/(b0-2·b1)`。

**修复后**：指数样本 → **(ξ, σ) = (-0.001, 1.001)** ✓；
另加 **GPD(ξ=0.25, σ=1) 逆变换样本**用例（只测 ξ=0 会漏掉"只在 ξ=0 处凑巧正确"的假修复）。

### WT-25 `hmm._forward_backward` —— `xi` 数值爆炸（**根因不是 `1e-300`** ✗）

**根因**：`denom` 的**索引放错了** ——
```python
denom = (alpha[t] * np.exp(lg[t + 1])) @ A.T @ beta[t + 1] + 1e-300
#        ^^^^^^^^^ 把 exp(lg[t+1]) 乘在【源状态 i】上
```
而分子 `numer[i,j]` 用的是**【目的状态 j】** ⇒ **denom ≠ Σnumer**（两者是两个不同的量）。
极可分数据下 denom **下溢为 0**，`+1e-300` 把它兜成 `1e-300` ⇒ xi 被放大 **1e300 倍** ✗。

**实测（修复前）**，`_two_cluster()` + `K=2`：
```
lg 范围: -3016.96 ~ 3.25
最大层和 = 2.55111e+300  (t=29)
  真实 denom(=Σnumer) = 2.55111      ← 正确层和就是 2.55
  代码 denom          = 1e-300       ← 下溢到 0 被兜住
```

**修法**：`denom = numer.sum()`（按分子张量**自身之和**归一）⇒ 每层和为 1、
每个 `(t,i)` 行和为 1；`denom == 0`（该转移不可能发生）时该层**保持全 0**，不再放大。
配套把 alpha/beta 的缩放换成 `_scaled_normalize`：和为 0 时**回退均匀分布**而不是
`0/0 = NaN`（否则 NaN 会一路污染 gamma/xi）。

**修复后**：层和恒 = **1.0** ✓、xi 全有限 ✓；退化发射概率（`exp(lg)=0`）⇒ xi 全 0、无 NaN ✓。
