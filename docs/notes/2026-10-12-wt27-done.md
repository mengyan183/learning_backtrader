### ③ 的技术难点为什么这样解

任务描述点名的坑：**先截 IS 再算因子**会让 IS 前段因子失真 ✗（`RANK_WINDOW=756` 等滑动
窗口在 IS 起点前没有历史）。所以顺序必须是：

```
全量 features ──recompute_targets(全量)──> 全量 target_position ──slice_split──> 评估用切片
     ↑ 因子/仓位都用全量算                                                    ↑ 只有回测吃切片
```

新增用例 `test_main_is_split_feeds_only_is_rows_to_backtest` 把这条**双不变量**都钉住了 ✓：
- `recompute_targets` 拿到的行数 > 2000（**确实是全量** ✓）
- 送进 `_sensitivity_metric` 的那份 `index.max() ≤ config.IS_END`（**确实只评 IS** ✓）
