## 二、🔴 Windows 端复核发现：两条判据存在**预登记缺陷**

### 缺陷 ①：判据③ 在**主口径**下是**循环论证**（零信息量）✗

代码事实（`scripts/verify_hypotheses.py`）：

```python
# 行 732-735：主口径挤压期定义
co_down = (qqq_ret < 0) & (tlt_ret < 0)
primary_mask = (co_down & (widen_bp > H065_SPREAD_WIDEN_BP)).fillna(False)

# 行 754-755：判据③ 的计数
sel = sq[(valid.reindex(sq) > 0) & qqq_down.reindex(sq).fillna(False)]
cofall = int(co_down.reindex(sel).sum())
```

推导：

```
主口径挤压期  ⊆  co_down                     （定义已含「TLT 也跌」）
⇒ cofall ≡ |挤压期 ∩ (corr>0)|               （sel 里 co_down 恒为 True）
⇒ 只要 |挤压期| ≤ 5，判据③ 必然触发，与数据无关
```

实测：主口径挤压期 **4 天**、`cofall = 0` ⇒ **必然触发** ✓（数字自洽，但**没有检验「股债同跌」** ✗ —— 它只是把挤压期天数**重数了一遍**）。

**为什么原意是好的**：判据③ 只有在**辅助口径**（VIX）下才有区分度 ✓ —— VIX 挤压期**不要求**股债同跌 ⇒ 445 天里同跌 61 天 > 5 ⇒ **不触发** ✓（**反向支持**假说）。但代码写死「**结论以主口径为准**」✗ ⇒ **主口径 × 判据③ = 坏组合** ✗。

**更深的根因**：主口径挤压期定义**含「TLT 也跌」** ✗ ⇒ 把**要检验的结论写进了自变量** ✗（循环定义）。

### 缺陷 ②：判据② 的**措辞与假说意图不等价** ⚠️

| | 措辞 |
|---|---|
| 假说 §④ 原文 | 低波动桶**也显著** ⇒ 才是避险失效 |
| 判据② 实现 | 低波动桶占比**不高于**全样本占比 ⇒ 不成立 |

实测低波动桶 **38.96%** ✓ —— 按假说意图（「也显著」）**39% 并不低** ✓，按判据②（须**高于** 45.07%）**判触发** ✗。**两者不等价** ⚠️。

### 缺陷 ③：阈值**无基准率标定** ⚠️

`H065_SPREAD_WIDEN_BP = 25.0`（行 124）系 **Windows 端拍定值** ✗ ⇒ 主口径挤压期仅
**4 天 / 2492 天 = 0.16%** ✗ ⇒ 该口径**不具备统计效力** ✗。
