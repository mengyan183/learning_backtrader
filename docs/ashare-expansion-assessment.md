# A 股扩展评估报告（L3.4，P3）

> 评估日期：2026-10-11 · 目的：判断 AKShare QVIX / A 股恐贪数据对贪恐系统（美股 TQQQ/SOXL/UPRO 主线）扩展的可行性。
> 结论：**独立支线可行（QVIX 免 key 可直接复刻 vix/price 因子逻辑）；与美股主线不合并（跨市场情绪不同构、权重混入无先验）。**

## 1. 数据源可行性核查

| 数据源 | 接口/口径 | 可用性 | 成本 | 证据 |
|---|---|---|---|---|
| **AKShare QVIX**（上证50股指期权波动率指数） | `index_option_50index_qvix`（日线）+ `index_option_50index_min_qvix`（分时） | ✅ 存在（单次返回全部历史；changelog 1.18.44 有修复记录） | 免 key、免费 | AKShare 官方数据字典 2026-09/10 版 |
| AKShare 50ETF 期权波动率指数 | `index_option_50etf_qvix` | ✅ 存在 | 免 key | 同上 |
| A 股恐贪指数（第三方现成） | miumiudashuju.com「MIUMIU 恐贪指数」（0-100、午间/日线、分级 ≤15 极度恐惧）；韭圈儿「A 股恐贪指数」 | ⚠️ 仅网页/社区展示，**无公开 API** | 免费但需爬 | 雪球 2026-06 数据（12.33 极度恐惧等），新浪财经引韭圈儿 |
| funddb.cn | 基金数据库 | ⚠️ 未检索到恐贪指数类公开接口 | — | 无官方恐贪 API 证据 |

**口径观察**：第三方 A 股恐贪指数分级（≤15 极度恐惧 / 15-40 恐惧 / 中性 / 贪婪 / ≥85 极度贪婪）与系统 ZONE_EDGES=[20,40,60,80] 思路同构但数值带不同，仅作思想参考。

## 2. 与贪恐系统（美股主线）的契合度

| 维度 | 评估 |
|---|---|
| 因子同构性 | QVIX 是 A 股 VIX 等价物 → **可复刻 vix 因子 + price 因子（波动率结构）的完整逻辑**（归一化、滚动分位、档位映射），复用 R1.1 评测协议与 M2.2 采纳通道 |
| 跨市场合成 | ❌ 不建议混入美股 WEIGHTS——A 股与美股情绪不同构（交易时段/制度/资金面差异），混入无先验且破坏因子可解释性 |
| 数据新鲜度 | QVIX 日线 T+1 可得（与 vix.csv 同节奏）；分时接口可支持盘中预览（L3.3 同构） |
| 环境兼容 | ⚠️ AKShare 新版要求 Python 3.11+，本机 venv 3.10 需装兼容旧版（1.14.x 或评估后升级 venv） |
| 免 key 纪律 | ✅ 符合（AKShare 免费、无 API key） |

## 3. 建议（独立支线，暂不落地）

1. **独立支线**：新建 `fg_system/ashare/`（或独立子仓库），QVIX → A 股 vix 因子 → 独立 0-100 指数，**不进美股合成权重**；若用户有 A 股持仓再接入个股档位。
2. **接入方案**（启动时执行）：`.venv/bin/pip install "akshare<1.15"`（3.10 兼容）→ `scripts/fetch_ashare_qvix.py`（日线增量 + 分时可选）→ 因子复用 `fg_system.factors.vix` 同构逻辑 → R1.1 评测（目标=沪深300 未来 5/10/20/40 日）。
3. **恐贪合成**：不采信第三方现成指数（无 API、口径不透明）；按「借思想不自引」原则，以 QVIX + A 股市场宽度（涨跌家数/成交额）自建，走 E4 因子门控。
4. **优先级**：P3 观察项——美股主线未饱和前不启动；用户明确要覆盖 A 股时再实施。
5. **待验证项登记**：AKShare QVIX 数据连续性（2018 年后中证暂停过 QVIX 官方发布，50 股指期权 QVIX 为衍生重构口径）→ 启动时先拉历史看断档再定。

## 4. 不合并的理由（纪律锚点）

- 系统边界（docs/system-boundary.md）：情绪系统按市场隔离，跨市场合成无先验、破坏可解释性。
- 权重先验：六因子权重均来自美股 OOS 证据；混入 A 股因子会污染 WEIGHTS v2.7 口径。
- 免 key/最小维护：QVIX 免费可测，但引入即新增 fetch + 评测 + 观测三条链，在主线 P0/P1 未清前不值得。
