## 一、官方档位（三档）

官网 ETF 页顶部刻度条锚点与标签：

```
-100           -60            60            100
 恐慌            中性            贪婪
恐慌 0 个   中性 54 个   贪婪 0 个
```

| 档位 | 系数区间（守猪待兔口径 -100~100） | 页面锚点证据 |
|---|---|---|
| **恐慌** | ≈ [-100, -60] | 锚点 -100 标"恐慌"；-60 标"中性" |
| **中性** | ≈ (-60, 60) | 锚点 -60/60 均标"中性"；当前计数"中性 54 个"落于此段 |
| **贪婪** | ≈ [60, 100] | 锚点 60 标"贪婪"；100 为贪婪端上限 |

- 官方**没有**"极恐/极贪"细分档（至少 ETF 页不展示），只有三档。
- 与服务端 API 下发的 `zone` 文本同源（本地实测样例："中性区间"）。
- 边界归属（-60/60 属哪侧）以服务端 zone 文本为准；本表区间为锚点语义的近似表述。

## 二、与系统档位（五档）的映射

守猪待兔量程 -100~100，系统量程 0~100；`loader.shoutu_to_system_scale` 用 `(x+100)/2` 映射。
守猪待兔贪/恐线 ±60 映射后为系统 80/20，与系统 `ZONE_EDGES=[20,40,60,80]` 两端精确重合。

| 守猪待兔官方档 | 守猪待兔分数 | 映射后系统刻度 | 系统档位（ZONE_NAMES） |
|---|---|---|---|
| 恐慌 | [-100, -60] | [0, 20] | 极度恐惧 |
| 中性 | (-60, 60) | (20, 80) | 恐惧 / 中性 / 贪婪（细分为系统三档） |
| 贪婪 | [60, 100] | [80, 100] | 极度贪婪 |

看板（dashboard）展示守猪待兔档位标签时：分数 → `(x+100)/2` → 套系统五档。
