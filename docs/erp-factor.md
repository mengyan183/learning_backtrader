## 2. 频率：**月度，不插值到日频**（2026-10-30 决策）

三条理由：

1. **前视偏差**（最致命）：multpl 的月度值**月末之后**才发布。
   按 `date` 对齐 = 「用当月还没公布的 PE 算当月信号」✗
   ⇒ 存 `available_date = date + 1 个月`，下游按它 ffill ✓
2. **插值制造假信号**：同一个月内 20 个交易日的 PE 是同一个数，
   插值成斜线会让滚动分位出现「月内平滑上升」的假趋势 ✗
3. **不产生新信息**：PE 的更新频率由季报决定，月度已是能拿到的最细粒度 ✓

## 3. 10Y 用**月均**对齐月度 PE（2026-10-30 用户裁定）

```
ERP_t = 1/PE_t − mean(DGS10, 该月)
```

理由：PE 是月度的，若用「月末那天的 10Y」会引入**日内噪声** ✗
（月末恰好是利率异动日 ⇒ ERP 被单日波动污染）。
月均与月度 PE 同频，两边都是「该月平均水平」✓

## 4. 分位窗口：**2520 交易日（10 年）**，不用默认 756

默认 `RANK_WINDOW=756` 对估值因子是错的 ✗：

```
756 交易日 ≈ 3 年 ⇒ 月度 PE 只有 36 个观测点
```

两个后果：分辨率不够（36 档）、覆盖不了一轮估值周期（5-10 年）✗
估值类因子的行业惯例就是 10 年（CAPE 本身就是 10 年平均）✓

**样本充足性**：PE 1871 起、DGS10 1962 起、评测起点 2019 ⇒ 需要 2009 起数据 ✓ 够。

## 5. CAPE 只作「分歧标记」，不作主信号

| 指标 | 用途 |
|---|---|
| **当期 PE** | **主信号** —— ERP 的经济含义天然对应当期盈利 ✓ |
| CAPE | 只算 `divergence = |PE分位 − CAPE分位|`，超阈值时标记「盈利可能不可持续」✓ |

**不用 CAPE 作主**：它用 10 年平均**实际**盈利 ⇒ 对盈利周期位置不敏感，
2020 疫情后 / 2023 AI 周期这种拐点会**严重滞后** ✗。

**不用两者平均**：慢变量 + 快变量混合 ⇒ 既不是「当前估值」也不是「长期估值」✗。

### 阈值：**跑通后按分布定**（2026-10-30 用户裁定）

初值 **25pp**（先验：两个高度相关的分位，实测分歧通常 10~20pp，25 ≈ 1.5σ），
但**最终以实际分布为准**：

```python
div = (pe_pct - cape_pct).abs()
thr = div.quantile(0.90)      # 取 P90 ⇒ 约 10% 的交易日被标记，可控 ✓
```

不用固定数字的原因：分歧幅度随盈利波动率变化（2010 年代小、2020-22 大），
固定阈值会在不同年代失效 ✗。

## 2026-10-30 实测：真实数据体检（修窗口 bug 后）

**踩坑**：`rolling_pct` 的 `window` 单位是**行数** ✗，而 ERP 是**月度**序列
（779 行）⇒ 传「2520 交易日」> 总行数 ⇒ **分位全 NaN** ✗（2520/1260 都是 0 个有效点 ✗）。
⇒ 月度序列必须按月计：**10 年 = 120 个月** ✓

修正后：

```
ERP 月度序列：779 行（1962-01 → 2026-10）
最新：PE=26.33 · 10Y 月均=5.15% · ERP=-1.35%

窗口 120 月：有效 660 点 · 最新分位 0.8%
窗口  60 月：有效 720 点 · 最新分位 1.7%
窗口  36 月：有效 744 点 · 最新分位 2.8%
```

**ERP = -1.35%，分位 0.8%** ⇒ 股权风险溢价**为负**，历史上只有 0.8% 的时间比现在更贵 ✗

### CAPE 分歧：实测 P90 = 40.8（不是初值 25）

```
660 个点：P50=11.7 · P75=27.7 · P90=40.8 · P95=50.0 · max=99.2
最新 = 30.8 ⇒ 未超 P90 ⇒ 不标记 ✓
```

**这印证了「按分布定阈值」的必要性** ✓ —— 用初值 25 的话，
P75 已经是 27.7 ⇒ 约 **30% 的月份**都会被标记成「盈利不可持续」✗，噪音太大。

⇒ 最终阈值取 **P90 = 40.8**（约 10% 的月份被标记，可控 ✓）。

**当前不标记的含义**：PE 26.33 和 CAPE 40.88 **都贵，但贵的程度一致**
⇒ 不是「一次性高盈利压低 PE」的失真，而是**整体估值就高** ✓
