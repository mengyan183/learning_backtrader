## 0. 一页结论

系统已具备完整的「每日数据链 → 六因子合成 → 信号 → 简报 → 进化设施」闭环（1104 个测试收集、每日 05:30 launchd 串行链、C/E 系列进化设施、ChromaDB 知识库、Flask dashboard 均已落地）。对照国内外开源贪恐与量化方案，本系统**最薄弱、最优先**的三件事是：

1. **因子评测协议不完整**——`factor_screen` 需按 Qlib 的 IC/RankIC + 分层净值 + 多空对冲 + 含/不含成本双口径升级，否则后续任何因子/权重改动「无裁判可依」；
2. **纪律尚未工具化**——「OOS 禁调参」「无未来函数」目前靠人守，应学 freqtrade 把 lookahead/recursive 自检变成 pytest 可执行测试；
3. **缺组合层与风险度量**——回测是 backtrader 单标的，无组合再平衡、无尾部风险量化，中远期补上（bt / vectorbt / Riskfolio-Lib 方向）。

归一化层面，成熟方案（alternative.me、CNN、qjr1997/fear-greed-index）无一用绝对阈值，全部是「当前值 vs 滚动窗口」映射到 0–100、50 为中性；本系统因子层已用 756 日滚动百分位（`config.py:96 RANK_WINDOW`），方向一致，但**档位边界 `ZONE_EDGES=[20,40,60,80]` 为固定值**，值得做对照实验（动态档位）后再按纪律决定是否变更。

**总原则：一律「借思想自实现」为主、「轻量直接引入」为辅**。明确避开：Qlib 的 RD-Agent（LLM 黑箱）、vn.py/LEAN（实盘重依赖栈错位）、zipline 默认数据 bundle（需 API key）、mlfinlab（商业授权）、国内量化平台（闭源 SaaS）。

### 2.3 设计模式收敛（综合观察）

- **归一化**：成熟贪恐方案无一用绝对阈值，全部是「当前值 vs 滚动窗口（30/90 天、125 日线、252 日、过去一年区间）偏离」映射 0–100、50 为中性。本系统因子层已符合，档位层为固定边界。
- **合成**：CNN 与 qjr1997 走「各子因子先独立 0–100 再等权」（等权稳健）；alternative.me 走显式加权（灵活）。本系统为固定先验权重，居中。
- **评测**：IC/RankIC + 分组累计净值 + 多空价差 + 含/不含成本双口径是量化行业事实标准（Qlib）；单因子 IC 高不代表组合有效，分组单调性才能辨真伪。
- **纪律工具化**：freqtrade 的 lookahead/recursive 自检、mlfinlab 的净化 CV/CSCV，把「回测裁判、OOS 禁调参」从口头变成可执行工具——是本系统最值得吸收的工程思想。

## 3. 开源框架引入取舍（明确结论）

**总原则：一律「借思想自实现」为主、「轻量直接引入」为辅；明确避开 LLM 黑箱、实盘重依赖、需 key 数据、商业授权。**

| 框架 | 结论 | 理由（结合单机/确定性/免 key/回测裁判/纪律） |
|---|---|---|
| Qlib | **借思想自实现** | 评测协议是现成蓝图；整体引入拖重每日 pipeline（torch/DL 栈）；RD-Agent 是 LLM 驱动，违反无 LLM 判决 |
| vn.py | **不引入** | 实盘交易框架（CTP 柜台/Qt GUI/C++ gateway），与离线研究定位错位，破坏 pytest 轻依赖环境 |
| backtrader | **保留现有使用** | 已在 `backtest/runner.py` 使用；订单级语义对照与 Cheat-on-X 审计有价值；但逐 bar 不适合大规模横截面扫描，GPL-3.0 与上游维护趋缓需知晓 |
| bt | **中期轻量引入或借思想** | 纯 pandas、MIT、单机秒级、免 key、确定性；撮合/成本模型较粗，与自建裁判互补不重叠 |
| zipline(-reloaded) | **借思想自实现** | 原库已死、reloaded 一人维护、依赖链长；默认数据 bundle 需 NASDAQ API key（违反免 key）；Pipeline 声明式 DAG 思想用纯 pandas 可自实现 |
| LEAN | **不引入** | C#/.NET 内核 + Docker 重体量，与 Python 单机栈割裂；离线研究拿不到云生态增量 |
| freqtrade | **借思想自实现** | 加密现货币实盘机器人，本体错位；但其 lookahead/recursive 自检与时序切分 CV 与回测裁判制完全同频，自实现成本低 |
| vectorbt | **远期点状引入候选** | 纯 pandas/numpy/numba、单机、免 key、确定性（固定 seed/cache 可复算）；只做扫描层，裁判逻辑仍自建；需先基准实验确认 Numba 确定性坑 |
| Riskfolio-Lib | **远期引入候选** | CVXPY 开源 solver 免 key、纯本地、凸优化可复算可 pytest；但属「组合层面定权」，前提是已有稳定因子打分，第 2 年增强项 |
| PyPortfolioOpt | **远期直接引入第一候选** | 比 Riskfolio 更轻、依赖更浅；若只需 max-Sharpe/min-vol/HRP 足够 |
| mlfinlab | **只借思想** | 公共仓库只收 issue，本体 Business/Enterprise 商业授权，不能免 key import；净化 CV/CSCV 算法公开、自写不长 |
| empyrical | **自实现** | 指标公式十几行可复算，避免再背 Quantopian 遗产依赖 |
| TA-Lib | **待验证后决定** | C 库需系统层安装、固定版本；若只需少量指标用纯 Python 实现更省环境 |
| 国内平台 | **不引入** | 闭源 SaaS，策略跑云端，数据/回测环境受平台约束，与单机确定性 pytest 体系交付形态错位 |
