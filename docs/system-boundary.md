# 系统定位与边界（P7）

> 目的：明确贪恐系统**做什么、不做什么**，防止工具被当成万能信号、防止
> 任何单一输出被当作"指令"。知识库沉淀（BenFelix 指数基金、all-time high
> 研究等投资理念 20 条）驱动了本文件的边界界定。

## 1. 系统定位（一句话）

**美股/加密多头仓位管理系统**：用市场情绪因子（五因子合成贪恐指数）+ 个股
系数 + 守猪待兔双系统，回答"现在该持有/加仓/减仓多少"，**不做空头、
不择时卖空、不日内交易**。

## 2. 硬边界（不做的事）

| 不做 | 原因 |
|---|---|
| 融券做空 / 做空 ETF | 系统为多头设计，做空信号无回测背书（知识库：卖空风险不对称） |
| 日内/分钟级交易 | 因子数据为日频，分钟信号无数据支撑 |
| 未经回测的变体入白名单 | 第 12.26 条：候选标的须回测+审批（见 docs/architecture.md） |
| 把裁判/归因输出当指令 | 全部 LLM 输出仅 🟡研究参考（见 §4 信号分级） |
| 公司电脑实时抓取 | `FG_STATIC_ONLY=1` 静态模式：不调富途/OKX 外部接口，只读本地 CSV |
| 预测单只个股涨跌 | 系统给的是"环境温度+仓位管理"，不是 alpha 选股器 |

## 3. buy-the-dip 评估规则（恐惧区的加仓纪律）

知识库：宏观政策/交易心理类沉淀（恐惧≠底部，但要敢接）。

| 条件 | 动作 |
|---|---|
| 系统指数 ≤40（恐惧区）且个股系数 < 守猪待兔 buy_line | 分批买入（1/3 步进，见行为清单） |
| 指数 ≤20（极度恐惧） | 只动用熔断释放的弹药，一次 ≤1/3 |
| 指数 40-60（中性） | 观望，不追涨杀跌 |
| 指数 ≥60（贪婪）且持仓已盈利 | 分批止盈；杠杆标的优先减 |
| 指数 ≥85（极贪熔断） | 熔断生效：核心仓降 floor，等待解锁信号 |
| BTC 未达手动目标价 | 观望持有（config.MANUAL_PRICE_TARGETS） |

**校验原则**：buy-the-dip 只在"情绪底+基本面无恶化"时执行；卖出理由须来自
基本面恶化或系统目标信号，而非单纯恐惧（行为清单第一条）。

## 4. 信号分级（所有输出统一标注）

| 级别 | 含义 | 举例 | 可否执行 |
|---|---|---|---|
| 🟢 实盘动作 | 已采纳规则触发 | 熔断减仓、BTC 达目标价卖出 | 可执行 |
| 🟡 研究参考 | 模型/因子分析 | 裁判裁决、深度归因、情绪面 | 仅参考 |
| ⚪ 待验证 | 假说/未回测 | H-xxx、MC 压力模拟 | 只观察不动作 |

## 5. 数据依赖与新鲜度底线

| 数据 | 文件 | 更新 | 过期警戒 |
|---|---|---|---|
| 指数/因子 | Data/features.csv | 每日链 | >3 交易日停更提示 |
| 持仓/账户 | positions.csv / accounts.csv | 每日链（富途/OKX 动态） | 快照日期滞后须注明 |
| 守猪待兔 | Data/raw/shoutu_fng.csv | 每日链 | 缺失直说"暂无系数" |
| FedWatch | Data/raw/fedwatch.csv | 每日链（qsid 自动刷新） | 缺失时 fed 节降级 |
| 价格 | Data/raw/prices.csv | 每日链 | 个股趋势/风控行降级 |

**新鲜度纪律**（scripts/check_freshness.py 每日写 Data/freshness_warning.txt）：
警告存在时，简报/看板顶部必须展示，不得假装数据是最新的。

## 6. 迭代守则

- 任何新信号/规则变更先进 `docs/变更记录`，再改代码，最后提交 git；
- 破坏性变更（改因子权重、改档位边界）必须写明依据（回测/实测/用户决策），
  禁止"凭感觉调参"；
- 公司电脑开发遵循：只读静态数据、不触发外部抓取、改动经 git 同步回家里电脑。
