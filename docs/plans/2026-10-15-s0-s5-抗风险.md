## Task 3（S-5）: 目标仓位 vs 实盘**偏离度**（**本批唯一新功能** ✓）

**为什么做** ✓：§1.5 的洞 —— 模型 `target_position` **5.7%~8.3%** ✓ vs 实盘 **100% 杠杆** ✗，
**没有任何地方把这俩放在一起看** ✗（已实测：**无现成工具** ✗）。

**设计（最小 ✓）**：

1. `fg_system/risk.py` 末尾加**纯函数** ✓：
```python
def target_vs_actual(target_position, net_value, market_value):
    """模型目标仓位 vs 实盘仓位的偏离（**只报事实** ✗ 不给指令 ✓）。

    返回 {"target", "actual", "gap_pp", "side", "note"}；
    任一输入缺失/非法 ⇒ 返回 None（**不猜** ✗）。
    """
```
   - `target` / `actual` 均为**占比**（0~1 ✓）；`gap_pp` = `(actual - target) * 100` ✓（**百分点** ✓）
   - `side`：`"over"` / `"under"` / `"on_target"`（|gap| ≤ 1pp 视为 on_target ✓）
   - 🔴 **不输出任何指令** ✗（不写"应减仓"✗）—— 只报偏离 ✓（对齐 §14.3 红线 ✓）

2. `fg_system/dashboard/report.py::_holdings_block()` 加**一行** ✓：
   `模型目标 X% · 实盘 Y% · 偏离 +Z pp（模型数据日 A / 持仓快照日 B）` ✓
   - 🔴 **必须同时显示两个日期** ✓（`features.csv` 09-18 ✗ vs `positions.csv` 09-22 ✗ ⇒ **日期本就不同** ✗，
     不显示日期就是**骗人** ✗）
   - 任一缺失 ⇒ 显示「数据不足（模型/持仓缺一侧）」✓（**不崩** ✓）

3. 测试：纯函数边界 ✓（缺失/零/相等/超配/低配 ✓）+ 持仓卡含该行且**日期都在** ✓

**⚠️ 纪律**：这是**展示** ✗ 不是**判决** ✗ ⇒ **不进** `pipeline`/`signal`/`target_position` ✓；
