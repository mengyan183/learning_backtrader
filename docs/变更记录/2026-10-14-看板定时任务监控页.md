# 2026-10-14 看板定时任务监控页（状态展示 + 一键重试）

- 状态：✅ 完成（commit 见下）
- 类型：P1 可靠性增强——监控闭环补上"人工介入"一环

## 背景

`3855b91` 落地了定时任务监控（飞书告警），但异常发生后**只能等**：
要手动进终端跑脚本。本次在看板（127.0.0.1:8000）新增「任务」页：
可视化全部数据/任务状态，**异常项在页面上直接点「重试」**。

## 做了什么

### 后端 `fg_system/dashboard/server.py`（make_handler 内新增两端点）

1. **`GET /api/tasks`** —— 复用 `scripts/task_monitor.collect_status()`（本次把
   检查逻辑抽成纯函数，CLI 与 API 共用同一份口径）：
   返回 12 项数据新鲜度 + 7 个 launchd 任务注册状态 + issues + all_ok。
2. **`POST /api/tasks/retry`** —— 页面「重试」：
   - **白名单映射**（12 项数据 → 对应抓取/合成脚本，见下表）——
     只允许映射内的命令，绝不执行任意输入，杜绝命令注入；
   - **后台执行**：`Popen` 立即返回（不阻塞页面），输出追加 `logs/task_retry.log`；
   - **互斥**：`Data/task_retry.lock` 记 target+pid，进程存活时新重试返回 409
     （防止并发重试写盘冲突）。

### 前端 `fg_system/dashboard/templates/index.html`

- 新增第 5 个 Tab「任务」（`data-name="任务"`）：
  - 汇总行（✅ 全部正常 / ⚠️ N 项异常）；
  - 表格：数据项 | 最后日期 | 状态（正常绿 / 停更 N 天红）＋异常行「重试」按钮；
  - 任务注册状态（已注册绿 / 未注册红）；
  - 重试后 15s 自动刷新本区块看恢复。
