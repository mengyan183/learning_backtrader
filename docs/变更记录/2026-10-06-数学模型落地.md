# 变更记录 · 数学模型落地（2026-10-06）

> 依据：用户"把所有可以落地的数学模型进行落地"。选择表中标 🔴"现在能做"的四项：HMM 状态识别、档位转移马尔可夫矩阵、EVT 阈值校准、贝叶斯更新假说信心。

## 变更

- 新增 `fg_system/models/` 包（纯 numpy/pandas，**零新依赖**——venv 无 scipy/sklearn/hmmlearn）：
  - `markov.py`：zone 序列 → 5×5 档位转移矩阵 + 稳态分布 + 自转移强度（惯性）+ 前瞻分布（N 日最可能档位）。
  - `hmm.py`：Gaussian HMM（K=3，观测=fg_index+vix+term+price+breadth 标准化五列）；Baum-Welch（scaled 前向-后向防下溢）+ Viterbi 解码；**多次重启选优**规避 EM 状态坍缩（实测默认 60 迭代会坍缩成两状态，restart=3 修复）。
  - `evt.py`：POT/GPD，概率加权矩（PWM）闭式估计 shape/scale（无 scipy）；重现水平公式反推 1/5/20 年极端指数值，对比现状边界（20/80）输出校准建议。
  - `bayes_update.py`：Beta-Bernoulli 后验（prior α=β=1），数值求 Beta 分位（无 scipy）；从 hypotheses.md 备注列提取"观察点/天数 X/N"语境计数 → 后验均值 + 95%CI。
- 新增 `scripts/model_report.py`：一键跑 4 模型 → markdown 摘要（stdout）+ JSON（`Data/model_report_YYYY-MM-DD.json`）供看板/简报引用。
- 新增 `docs/blocked-registry.md`：全部未落地/受阻塞实现登记表（A 外部依赖 / B 数据积累 / C 回测后 / D 可先做）。
- 新增 `docs/变更记录/README.md`：变更记录总索引 + 89 commits 覆盖审计。

## 口径与实测（2026-10-06，数据 2019-10-03~2026-10-05，1759 交易日）

- **马尔可夫**：档位惯性均值 76%；稳态最可能=中性(35%)；当前中性 → 未来 5 日最可能中性(42%)。
- **HMM**：当前 regime=中性；三态全活（恐惧 620 天 fg≈34 / 中性 446 天 fg≈57 / 贪婪 447 天 fg≈72）。
- **EVT**：极恐现状边界 20 → 数据建议 3.2（1 年重现）；极贪现状 80 → 建议 89.2。结论：现状 20/80 触发偏频（约 5.8%/2.3% 时间），真实 0.4% 极端尾部更远——**仅供人工参考，未改 config**（红线：OOS 禁直接调参）。
- **贝叶斯**：H-001 3/20 → 后验 0.18 [0.05,0.36]；H-002 3/3 → 后验 0.80 [0.40,0.99]。
