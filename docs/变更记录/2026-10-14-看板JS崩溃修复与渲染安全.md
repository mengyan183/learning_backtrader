# 2026-10-14 看板页面 JS 崩溃修复 + 渲染安全防护

- 状态：✅ 完成
- 类型：P0 线上故障（看板 tab 失效、内容不显示）

## 故障现象

看板页面出现：有内容不显示（图表空白）、底部 tab 无法点击。

## 根因（Chrome headless console 定位）

```
Uncaught SyntaxError: Unexpected token ';'   （页面文档第 155 行）
Uncaught ReferenceError: INDEX is not defined（后续脚本连锁失败）
```

页面 HTML 第 155 行渲染出：

```js
var HUMAN30 = ;
```

模板 `index.html` 引用了 `{{ human30_json }}`，但 `report.render_html` 的
render 参数**从未传 human30_json**（也缺 `human30` 区块变量）——Jinja2 对
未定义变量渲染为空 ⇒ `var HUMAN30 = ;` ⇒ **整个内联 <script> 块解析失败**
⇒ tab 绑定、图表初始化、实时行情轮询全部不执行。

**为什么"经常出现"**：单页大 JS（主块 ~500 行）+ 数据经 Jinja 注入成 JS
字面量；**任何**一个注入变量为空都会让整页 JS 挂掉，而此前测试只校验
「HTML 字符串包含某片段」，从未校验「渲染后的 JS 可解析/运行时无错」。
本次的 human30 注入缺失是 `cc3f5a3`（10-13 公司端同步覆盖 report.py）引入，
同步后一直潜伏，直到本次页面改动重启后暴露。

## 修复

1. **report.py**：render 参数补上
   - `human30=_human30_block()`：Human 3.0 状态卡（最新记录聚合 + 意识层级 +
     连续未打卡提醒 + 四象限明细，无记录给提示文案）；
   - `human30_json=_json(_human30_dashboard_json())`：雷达/趋势图数据
     `{dates, keys, labels, series, avg, latest}`，无记录返回 None → 渲染为
     `null`（合法 JS，前端有守卫静默跳过）。
2. **index.html**：全部 5 个 `var X = {{ x_json }};` 注入行统一加
   `| default('null')` 兜底——今后任何变量漏传只影响对应区块，**不再整页崩**。
3. **防护测试** `tests/test_dashboard_render_safety.py`（3 条）：
   - 渲染 HTML 不得出现 `var X = ;` 空注入（语法级红线）；
   - HUMAN30 注入值必须是 `null` 或 JSON 对象；
   - 所有注入变量渲染后非空。
