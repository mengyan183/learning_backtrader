## 口径
### 1. `test_index`（4 个失败）：四因子 → 五因子断言
- 实现已升级到五因子（`config.WEIGHTS={vix:0.30, term:0.15, price:0.25, breadth:0.15, fed:0.15}`），
  测试仍按四因子断言。修复：加权测试补 fed 列、期望值按新权重重算（0.30×100+0.15×100=45.0）；
  因子顺序断言 vix/term/price/breadth/fed；缺 fed 时按剩余四因子重归一化。

### 2. `fetch_throttle` / `shoutu_api`（5 个失败）：`_opener()` 签名
- 2026-10-06 代理分流把 `_opener()` 改为 `_opener(url)`（按 `config.PROXY_HOSTS` 白名单分流，
  `_OPENER` 从单值变 dict），测试 mock 仍是无参 lambda。修复：所有 `lambda:` → `lambda url:`；
  `test_opener_is_reused` 改为 `_OPENER.clear()` 后同 URL 桶复用断言。

### 3. `shoutu_page_query`（3 个失败）：fetch_shoutu.py 编排层重建
- 之前重建时只留 bsk 薄封装，丢失页面编排契约。整文件重建为完整编排层：
  `main()` 先收齐 vals+prices 再 `append_records`（查询失败抛错不落盘）；
  全市场表零命中提前退出；`missing_symbols` 成本闸门决定补查标的（AXTX/CRCG 不得以带引号字面量出现）；
  价格双来源（分类表 universe_prices + 查询面板 price）都落盘；`query_one_js` 用 `const CODE="<SYM>";`
  单层引号 + `getClientRects()` 面板可见性。
- 结果：19 passed / 3 skipped（skip 为 conftest `_CASE_DEPS` 设计内：依赖文件
  `scripts/shoutu_page_query.js` 与 `compare_shoutu.py` 本机不存在）。

### 4. `dashboard/test_report`（1 个失败）：static/style.css 守卫
- 模板实际引用 `/static/style.css?v=20261005b`（cache-buster），测试精确匹配无版本后缀。
  修复：改为前缀断言 `'href="/static/style.css'`（守卫语义不变：独立样式文件 + 内含
  `@media` + `max-width:600px`）。

### 5. `test_pipeline` lookahead（1 个失败，真 bug）：fed 因子不随 shift 平移
- 根因：fed 因子按日历重算（`config.FED_POLICY_PERIODS`），不随 `shift_inputs` 平移；
  其余四因子读平移后的 wide 值 → 政策切换日（实测 2026-01-02、2026-09-16）混用
  「后移因子 + 未后移 fed」，触发前视偏差校验假阳性。
- 修复：`pipeline.load_wide` 在 `shift_inputs>0` 分支先把 fed 分数写成
  `wide[("FED","score")]` 列再整体 `shift()`；`fed.py` 的 `score()` 检出该列
  （MultiIndex）即直接返回（shift=0 生产路径无该列，行为与历史一致）。
- 验证：overlap 2519 天 diff max = 0.0。
