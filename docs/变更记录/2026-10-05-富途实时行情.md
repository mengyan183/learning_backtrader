# 变更核实记录：富途实时行情 4 项增强

> 对应 2026-10-05 用户批准"按照上面建议顺序执行"的富途实时行情增强：
> ①持仓实时浮盈亏 ②盘中指数预览 ③盘中异动→新闻联动飞书告警 ④launchd 开机自启。
> 前置确认：富途当前仅用于持仓/资产同步与新闻检索（sync_positions + invest_research），
> 实时订阅是纯增益增强，不改变每日收盘信号口径。

## 变更

新增 `scripts/futu_realtime.py`（常驻订阅服务，flock 单实例锁）：

1. **实时行情订阅**：`OpenQuoteContext.subscribe(US.<symbol>, ["K_1M"], subscribe_push=True)`
   + `CurKlineHandlerBase.on_recv_cur_kline` 回调；订阅无数据 180s 后自动降级
   `get_market_snapshot` 15s 轮询。标的 = 持仓快照最新行的美股 symbol（去 -USDT）+ QQQ。
   每标的最新价/当日涨跌%/时间戳实时写 `Data/realtime_state.json`。
2. **盘中指数预览**：用实时 QQQ 价替换 wide 尾行 → 重算 `PriceFactor.score`，
   其余因子（vix/term/breadth/fed）取 features 尾行 → `index.combine` 合成预览指数，
   写入 `preview_index` 字段（fg_index/zone/closed_index/delta）。**绝不写 features.csv/signals**。
3. **盘中异动告警**：|当日涨跌%| ≥ `RT_ALERT_PCT`（默认 5.0）→ `get_search_news` 抓新闻归因
   → `invest_research.push_feishu` 推送"⚠️ 盘中异动"；每标的 3600s 冷却去重。
   触发口：初始快照、K_1M 回调、主循环 60s 全量兜底。
4. **开机自启**：`~/Library/LaunchAgents/com.xingguo.fg-realtime.plist`
   （RunAtLoad + KeepAlive，日志 `/tmp/fg_realtime.log`，env `FG_REALTIME_OFF` 可一键关闭）。

看板侧修改：

- `fg_system/dashboard/server.py`：新增 `GET /realtime`（读 realtime_state.json，无服务 404）。
- `fg_system/dashboard/report.py`：持仓卡 `.h-card` 增加 `data-sym` 属性。
- `fg_system/dashboard/templates/index.html`：`setInterval(10s)` 轮询 `/realtime`，
  按 `data-sym` 更新持仓卡现价（`●` 实时标记）/浮盈亏/过程成本；`#rtBar` 显示盘中预览徽章。
- `fg_system/dashboard/static/style.css`：`.rt-dot`（呼吸动画）/`#rtBar` 样式。

## 依据

- 用户 2026-10-05 批复：实时订阅按 4 项顺序执行；盘中只做"预览"不写正式信号（信号口径一致性优先）。
- 实测富途 API：美股 K 线订阅 subtype 枚举为 `K_1M`（非 KLINE_1M）；快照前收列名 `prev_close_price`；
  订阅回调类为 `CurKlineHandlerBase`（非 KLineHandlerBase）。

## 口径

- 盘中预览指数 = 实时 QQQ 价参与 price 因子重算 + 其余 4 因子收盘值合成，与收盘 fg_index 同权重表
  （vix 0.30 / term 0.15 / price 0.25 / breadth 0.15 / fed 0.15）。
- 预览值与收盘值差异 = delta；看板标注"仅预览，正式信号以收盘为准"。
- 告警阈值默认 ±5%，`RT_ALERT_PCT` 环境变量可调；告警消息注明"仅供研究，不构成操作指令"。
- 非交易时段无新 K 线，状态文件保持最后值，属正常。

- 市场页显示盘中预览指数徽章（2026-10-05 首算 54.9 中性，与收盘一致，Δ0.0）。
- 盘中异动（|涨跌|≥5%）自动推送飞书；2026-10-05 21:2x 实盘触发 YINN(-6.5%)/AXTX(+9.9%)/CONL(-6.6%)
  共 3 条告警，push=True 成功。
- 不改变每日链 features.csv / signals / 正式信号。

## 变更

1. **盘前误报修复**：`check_alert()` 增加交易时段门卫 `_in_trading_hours()`
   （美东周一至周五 09:30–16:00）。根因：盘前/盘后/周末富途 snapshot 的
