# 变更核实记录模板

> 借鉴 HowToLiveBetter 的 101 份核实记录（docs/核实记录/）：每次影响**生产口径**的变更
> 必须留一份记录，可审计。新增文件命名：`YYYY-MM-DD-<主题>.md`。

## 变更
（一句话：改了什么，涉及哪个文件/哪个参数）

## 依据
（为什么改：用户决定 / 现象 / 证据，注明日期与来源）

## 口径
（新旧口径对比：公式、参数、边界，可复核）

## 影响
（对指数/信号/简报的量化影响：历史偏差、最新值变化）

## 验证
（怎么确认生效：命令、输出、渲染检查）

## 提交
（git commit hash 与日期）
