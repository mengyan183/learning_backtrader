# 2026-10-14 定时任务与数据新鲜度监控系统落地

- 状态：✅ 完成
- 类型：P1 可靠性增强（防"任务异常 → 数据缺失 → 多日不发现"）

## 背景

近期两次数据层事故暴露同类盲区：VIX/sentiment 上游 T+1 停更 1 天（审计误报）、
shoutu_history 停更 6 天才被发现。现有 `check_freshness.py` 只查 features/prices
两个文件且**不推送**。需要一个覆盖全部数据 + 定时任务注册状态、异常即告警的监控闭环。

## 做了什么

1. **新增 `scripts/task_monitor.py`**（纯标准库，零新依赖）：
   - **数据新鲜度**：12 类数据（features/prices/vix/sentiment/putcall/fedwatch/
     kalshi_fed/funding_rate/shoutu_fng/shoutu_history/news_sentiment/stablecoin_usage）
     按 date 列最大日期 vs 今天，容忍自然日窗口（3~7 天，吸收周末、节假日与上游
     T+1 发布滞后；shoutu_history 为 bsk 条件抓取容忍 7 天）；
   - **launchd 注册状态**：贪恐 7 个定时任务是否仍在 `launchctl list` 中（任务消失即报）；
   - **mtime 兜底**：date 列缺失/解析失败时按最后修改时间判断；
   - **飞书告警 + 去重**：异常时推送（复用 `invest_research.push_feishu`），
     `Data/monitor_state.json` 同日同项只推一次，跨日重置，避免每日多次检查轰炸。
2. **新增 `tests/test_task_monitor.py`**（4 条）：全部新鲜=0 / 停更=1 / 文件缺失=1 /
   任务未注册=1。
3. **新增 launchd** `com.xingguo.fg-monitor.plist`：每日 **07:30 / 15:00 / 23:30**
   运行 `task_monitor.py --push-alert`，日志 `logs/task_monitor.{out,err}.log`。
