# A2-E 设计：keyed extremes 的**量级量化**

- 日期：2026-09-28
- 前置：A2 已交付（HEAD `b346e8a`）。**通路已建、两开关默认关**。
- 本文只解决 A2 留下的一条待办：**keyed extremes 的效果完全未量化**。

---

## 1. 问题与目标

A2 建好了 `shoutu_keyed_extremes`（熔断 / 极恐的**触发源**改用守猪待兔口径的市场级指数），
但 spec §9.3-4 明确记着「**其量级尚未评估**」。没有量级就无法判断扳开它是否值得 ——
这正是 §14.5 O4 所要求的「**组合级证据**」。

**目标**：给出「把极端规则的触发源换成守猪待兔口径」对**组合级**表现的**量级估计**。

**已有的一条强提示**（A2 最终评审实测，单窗口）：

```
keyed 口径：熔断触发 60 天 | 极恐触发 17 天
市场指数口径：熔断触发  3 天 | 极恐触发  4 天
```

⇒ 守猪待兔口径的触发频率**高一个量级**。这直接说明本项**必须做**：极端规则会豁免防抖动
（`market_target` 的 `extreme=True` ⇒ `throttle_ok` 直接放行），触发频率高一个量级意味着
**换手与交易成本可能大幅上升**，而 A1 的结论完全没覆盖这一维度。

## 2. 与 A1 的关系（正交维度，不可互相替代）

| | A1 | 本项（A2-E） |
|---|---|---|
| 量化什么 | **五档 core 的来源**（清仓线 V1/V2/V3） | **极端规则的触发源**（熔断 / 极恐） |
| 注入点 | `run_portfolio(us_core=)` | `run_portfolio(us_trigger_index=)` |
| 结论 | 不建议做 A | **本项只出数，不判定**（§4） |

两个维度**正交**（A2 已用独立开关实现），必须**分别**量化。

## 3. 口径（必须随结果一起读）

| 项 | 口径 |
|---|---|
| **曲线集** | **8 条** = `{B0, V1, V2, V3}` × `{keyed=False, keyed=True}`。`B0` = `us_core=None`（基准，五档 core + 市场指数触发源） |
| **双窗口** | **全历史** + **纯效应段**（`2024-04-23` 起）。⚠️ keyed 在历史区间**逐位等价 `fg_index`**（A2 spec §6 性质）⇒ 只有纯效应段可能有差异 |
| 样本 | **主样本** 3 标的（`config.SYMBOLS` = TQQQ/SOXL/UPRO）；另附**全样本**对照（`config.SHOUTU_SYMBOLS` 中服务端有历史者 = 6 标的） |
| 组合级指标 | 年化 / 最大回撤 / **Calmar** + **高情绪区间相对收益差**（`H = {t : fg_index_t ≥ 80}`，与 A1 同定义） |
| 组合口径 | **加权篮子 + `FgStrategy` 单组合**（本仓库既定做法，与 A1 / `cli backtest-v2` 同口径） |
| 成本 | 佣金 / 滑点按 `config.COMMISSION` / `config.SLIPPAGE`（回测内）；**未建模**汇率 / 税 / 借券 |
| 显著性 | **不做**（事件重叠、单段行情、非独立样本 —— 同 A1） |

**三条必须明示的口径**（随结果一起写）：

1. **只换指数条件**：熔断解锁的**价格条件**（标的自低点反弹 `EXTREME_GREED_UNLOCK_REBOUND`）**不变**；
   极恐的阈值换成 `CRYPTO_EXTREME_FEAR_TRIGGER` 只对 crypto 生效（本项只跑 us_equity）。
2. **`V2`/`V3` 在 `2024-04-23` 之前会改变输出**（回退到市场指数后仍套用各自的变体表）——
   只有 V1 与该日之前的基准逐位重合（同 A1）。故全历史窗口对 `V2/V3` 的含义是
   「**变体表 + 该日之前用市场指数回退**」，**不是**「效应的稀释版」。
3. **keyed 的历史区间零影响** ⇒ 若纯效应段之外出现差异，说明实现有问题（应作为红线）。

## 4. 判据（**先写死，不因结果修改**）

**不设 go 门。** 依据 A2 spec §9.4（已获批准）：「扳开条件**沿用 §14.5 O4**（真实操作 ≥ 3 次复盘质疑 /
**组合级证据**），**不新增量化门槛**」。本项的作用是**提供那份组合级证据**，不是另立一道门。

⇒ 本 spec **明确不给出「该不该扳开」的结论**。理由：一旦设阈值并用回测去比，就滑向
「用回测挑参数」（第 13.1 / 13.2 条明令禁止）。

**但「必答项」写死**（缺任一项即视为本项未完成）：

| # | 必答项 | 为什么必答 |
|---|---|---|
| 1 | 8 条曲线的组合级指标（年化 / 回撤 / Calmar），**双窗口** | 主结果 |
| 2 | `keyed=True` 相对 `keyed=False` 的**增量**（年化差、Calmar 差） | 直接回答「keyed 带来了什么」 |
| 3 | **触发频率对照**：keyed 口径 vs 市场指数口径的熔断 / 极恐**天数**（按窗口分别统计） | 解释机制；已知单窗口 60/17 vs 3/4 |
| 4 | **换手 / 交易次数变化**（`extreme=True` 会**豁免防抖动** ⇒ 调仓次数上升） | 触发频率高一个量级的直接后果，A1 未覆盖 |
| 5 | 主样本 vs **全样本**的稳健性对照 | 主样本小、旁证大（A1 的教训） |

**明确不做**：不做显著性检验；不挑「最优组合」；不改任何默认值；不据此调任何阈值。

## 7. 风险与未知

| # | 风险 | 处理 |
|---|---|---|
| 1 | 8 曲线 × 2 窗口输出量大，易淹没结论 | 分表：①组合级主表 ②增量表 ③触发频率/换手表 ④稳健性对照表 |
| 2 | `extreme` 豁免防抖动 ⇒ 换手上升，成本影响可能主导结论 | **必答项 4** 单独报告；并报告「含成本 / 不含成本」两版年化 |
| 3 | 守猪待兔历史仅 2.4 年 | 明示为**量级估计**（同 A1） |
| 4 | keyed 在历史区间零影响 | 作为**实现正确性红线**（若出现差异 ⇒ 实现有问题） |
| 5 | 触发频率高一个量级可能让结果被少数极端日主导 | 报告触发日的分布（哪几天、集中在哪些月份） |

## 8. 测试策略

1. **纯函数单测**（若新增统计函数）：触发天数 / 换手统计的正确性

3. **静态守卫**：脚本不得硬编码变体表 / 标的（沿用 A1 的 `test_script_does_not_hardcode_*` 做法）
4. **默认零影响**：本项**不改**生产代码 ⇒ 既有 `775 passed` 必须保持
