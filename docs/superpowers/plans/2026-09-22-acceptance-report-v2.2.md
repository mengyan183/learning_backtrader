## 二、缺陷 2：弹药仓上限 30% → 12%

### 2.1 变更内容

| 项 | v2.1 | v2.2 |
|---|---|---|
| `AMMO_CAP` | 30% | **12%** |
| `AMMO_PER_BATCH` | 10% | **4%** |
| 总仓位上限 | 75% | **57%** |
| 大盘最大暴露 | 61.5% | **43.5%** |
| 永久现金缓冲 | 25% | **43%** |

### 2.2 为什么这是真实缺陷（取证）

| 证据 | 数值 |
|---|---|
| 弹药池释放时点 | **2018-01-17 / 2018-02-02 / 2018-11-16**（全区间仅此 3 次） |
| 耗尽后恒定占比时长 | **1967 个交易日 = 7.8 年**，不再随任何信号变化 |
| 性质 | **永久仓位下限**，不是「储备」——与设计初衷不符 |
| 保护措施 | **零**。趋势过滤（第 4A 条）只作用于核心仓 |
| 2026-06 崩盘窗口占比 | 弹药占目标仓位 **57.3%**，是回撤的最大来源 |

### 2.3 变更依据（总暴露预算分解，非拟合）

```
总最大暴露 × 最坏崩盘深度 ≤ -40% 回撤预算
3x 标的最坏崩盘深度 D = 90%（SOXL 2022 实测 -90.51%）
⇒ 总最大暴露 ≤ 40% / 90% = 44.4%
⇒ 31.5%（大盘核心仓满仓）+ AMMO_CAP ≤ 44.4%
⇒ AMMO_CAP ≤ 12.9%   ⇒  取 12%
```

**为什么不能假设核心仓在崩盘中「被保护」**：核心仓有两条独立保护（趋势过滤 ×0.5、
五档饱和度 0.25–1.0），理论上最坏暴露仅 15.75%。但 **2026-06 已实测发生反例**：
该窗口 `trend_blocked = 0/27 日`，趋势过滤**完全没有提供保护**。故预算分解必须按
「**两者均无保护**」的最坏情形做。

**为什么只砍弹药**：核心仓有**两条**独立保护，弹药**一条也没有**。
同一预算下，**无保护的那一项必须自己承担全部最坏情形**。

## 三、缺陷 1：趋势基准 —— 取证后决定**不改**

v2.1 报告 §六 的候选方案是「按标的各自的无杠杆底层（TQQQ→QQQ、SOXL→SOXX、UPRO→SPY）
取最保守者」。**取证结论：该方案无效；换均线周期同样无效。**

证据（`Data/raw/prices.csv` 全区间 2016-09 ~ 2026-09，2514 交易日）：

| 检查项 | 结果 |
|---|---|
| 崩盘窗口 SOXX 相对自身 200 日均线 | 从 **1.658 只跌到 1.161**——**全程未跌破**，谷底仍在均线上方 **16%** |
| 同上窗口 200MA / 150MA 触发天数 | **0 / 27** 日（QQQ、SOXX、SPY 全部 0） |
| 同上窗口 100MA 触发天数 | 1 / 27 日 |
| 同上窗口 50MA 触发天数 | SOXX 12 / 27 日，但**全区间触发率 32.5%**（任一底层 39.3%） |
| 20MA 全区间触发率 | 任一底层 **45.2%**——近半数时间，已不是趋势过滤 |
| 2022 熊市覆盖（SOXX） | 200MA **86.5%** > 150MA 86.1% > 100MA 78.9% > 50MA 70.1% > 20MA 62.2% |

**结论**：

1. **换成按标的的基准不会触发**——SOXX 自己也没跌破 200 日均线。原假设（基准选错）**不成立**。
2. **换更短的均线得不偿失**：要抓住这次 27 日的崩盘需 ≤50MA，而 50MA 全区间触发率 32.5%，
   且**对 2022 熊市的覆盖反而从 86.5% 降到 70.1%**——快均线在剧烈反弹中会反复翻回均线上方。
   **200 日均线对「持续熊市」（§6.1 设计初衷、v1 根因）是最优的，对「快速板块崩盘」结构性无效。**
3. **禁止为单个 27 日事件调 `TREND_MA_DAYS`**——那是过拟合，且会**劣化**它原本擅长的场景。

**接受的局限**：200 日均线无法覆盖「从高位快速回落 ≤30% 的板块级崩盘」——
此类崩盘只有经 3x 杠杆放大后才被感受到（SOXX -29% → SOXL -69%）。
若将来要覆盖，应新增**独立机制**（如快速跌幅闸门），且需独立走第 8 条流程。

### 4.1 必须诚实披露：本次下调主要是「风险与收益的同比例缩放」

| 标的 | v2.1 Calmar | v2.2 Calmar | 判定 |
|---|---|---|---|
| TQQQ | 0.379 | 0.377 | ≈ 不变 |
| SOXL | 0.386 | **0.309** | ⚠️ 变差 |
| UPRO | 0.270 | 0.254 | 略变差 |

**含义**：年化收益从 16.41% 降到 10.62%（TQQQ）**不是效率损失**，而是主动降杠杆。
**价值在于满足「回撤上限」这一约束**（`trading-discipline.md` 的核心目的是「管住手」），
**不在于提高收益效率**。若你的偏好是高收益而非低回撤，v2.1 的 61.5% 暴露更优。

### 4.2 SOXL 剩余缺口的归因（全部来自样本外单一事件）

- SOXL 样本内 **-32.04%**——**已达标**。
- 剩余 -51.32% **完全来自样本外 2026-06/07 的板块崩盘**（27 日，SOXL -69%）。
- 该窗口仓位从 46.6% 降到 28.6%（**-39%**），回撤只降 8.52pp
  ⇒ **MDD 对暴露的弹性 ≈ 0.45**，远非线性。
- 原因是 SOXL 的 MDD 是**两次崩盘叠加且未回本**的累计回撤
  （2024-25 崩 -88% + 2026-06 崩 -69%，中间未创新高）。这是持有 3x 板块 ETF 的固有性质。
- 该崩盘**无法被趋势过滤覆盖**（§三已证明）。

## 五、为什么不再继续下调以凑 SOXL 的 -40%

**明确拒绝**：

1. **需要把总暴露降到约 25%**（按弹性 0.45 反推：43.5% × (40/51.32)^2.2 ≈ 25%）。
   而 TQQQ/UPRO 已在 **-28% / -29%**，**远超目标**——为救 SOXL 而牺牲它们是**纯浪费**。
2. **那是对单个 27 日事件的拟合**。§三已证明该事件**结构性不可被趋势过滤覆盖**，
   继续降暴露只是在为历史路径买单。
3. **正确方向是修结构，不是降总量**：当前 `us_equity` 内三个标的**等权**
   （`WEIGHTING = "equal"`），而 SOXL（3x 半导体）的波动率显著高于 TQQQ——
   **等权等于超配 SOXL 的风险**。按波动率反比加权才是对症的规则级修正。

## 六、新发现（未实施，需人工决策）

### 缺陷 3：`us_equity` 内等权配置超配了高波动标的

- **现状**：`WEIGHTING = "equal"`，TQQQ / SOXL / UPRO 各 1/3。
- **证据**：SOXL（3x SOXX）的波动率与崩盘深度显著高于 TQQQ / UPRO
  （买入持有回撤：SOXL -90.51% vs TQQQ -81.75% vs UPRO -76.82%；年化波动率 1.03 vs 0.67 vs 0.54）。
  等权 ⇒ 风险贡献严重不均，SOXL 主导了整个组合的回撤（-51.32% vs -28% / -29%）。
- **候选方案**（需独立走第 8 条流程）：
  - **A. 波动率反比加权**（风险平价）：权重 ∝ 1/σ。使风险贡献均等。
  - **B. 按标的各自设上限**（如 SOXL 单独上限更低）。
  - **C. 维持等权**，接受 SOXL 主导回撤。
- **注意**：v1 §7.2 已预留「v2 可改 `factor` 加权」；但改权重要求回测确认，
  且**禁止用全样本优化权重**。
