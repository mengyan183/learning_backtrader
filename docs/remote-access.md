# 不在家时访问仪表盘

**问题**：家里 Mac 上跑着仪表盘服务，人在外面（公司 / 出差）怎么打开？

> **⚠️ 先读这段**
> 仪表盘页面里有**你的持仓指令**，而服务**默认无鉴权**。
> ⇒ **绝对不要**把 8000 端口直接映射到公网。
> ⇒ 正解是**先建一条加密隧道**，让你「人在外面，但网络身份在家里的局域网」。

---

## 0. 先搞清楚两件事

### 0.1 你家宽带有没有**公网 IPv4**？

**大多数家庭宽带没有**（运营商 CGNAT）。这时**端口映射、IPSec 服务端全都无效**，
不管路由器怎么配。

**自测**：登录路由器后台看 **WAN 口 IP**，然后对比百度搜「我的IP」的结果。

| WAN 口 IP 长这样 | 结论 |
|---|---|
| `10.x.x.x` / `100.64~100.127.x.x` / `172.16~31.x.x` / `192.168.x.x` | ❌ **内网地址，没有公网 IP** |
| 与「我的IP」显示的地址**不一致** | ❌ 被 CGNAT 了 |
| 一致，且是正常公网地址 | ✅ 有公网 IP |

> `100.64.0.0/10` 是运营商级 NAT 专用段 —— 家庭宽带里最常见的一种。

### 0.2 你的路由器（锐捷 EG105G-P-L）能做什么

| 能力 | 支持？ | 说明 |
|---|---|---|
| **Easy VPN**（锐捷异地组网） | ❌ **不支持** | 官方明确「**EG105G-P-L 和 EG105GW 不支持 Easy VPN**」 |
| IPSec VPN | ✅ 支持 | EG 系列有 IPSec 配置，具体项随固件版本而异 |
| 端口映射 / DDNS | ✅ 支持 | — |
| 云管理（睿易 APP） | ✅ 支持 | — |

⇒ **不支持 Easy VPN** 意味着锐捷那套「一键异地组网」在你这台机器上用不了。

## 1. 方案对比

| 方案 | 需要公网 IP | 需要改路由器 | 加密 | 难度 | 结论 |
|---|---|---|---|---|---|
| **Tailscale** | ❌ | ❌ | WireGuard | ⭐ | ✅✅ **首选** |
| **蒲公英**（贝锐） | ❌ | ❌ | 有 | ⭐ | ✅ 国内网络更稳 |
| **frp + 云服务器** | ✅（服务器要有） | ❌ | 需自配 | ⭐⭐⭐ | 可控但费钱 |
| **路由器 IPSec VPN** | ✅ 必须有 | ✅ | IPSec | ⭐⭐ | 有公网 IP 才可行 |
| **端口映射** | ✅ 必须有 | ✅ | ❌ 无 | ⭐ | ❌ **不要用** |

## 2. 首选：Tailscale（最省事）

**为什么选它**：不需要公网 IP、不需要动路由器、端到端加密、个人用免费额度足够。

> 原理：两端都**主动向外**连接，NAT 打洞建直连；打不通就走中继。
> 所以**不需要你家有公网 IP**。

### Mac 上（一次性）

1. 下载安装：<https://tailscale.com/download/mac>
2. 登录（Google / GitHub / 邮箱均可）
3. 查本机的 Tailscale IP：

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale ip -4
# 输出形如 100.101.102.103
```

### 手机上（一次性）

1. 应用商店装 **Tailscale**
2. **用同一个账号登录**（⚠️ 两端账号必须一致，否则看不到对方）
3. 打开开关

### 访问

手机浏览器打开：

```
http://100.101.102.103:8000/
```

**跟在家一样**，只是地址从 `192.168.x.x` 换成了 `100.x.y.z`。

> 一样可以「添加到主屏幕」，图标照旧。

---

## 3. 备选：蒲公英（国内网络更稳）

Tailscale 的控制面在**国外**，国内有时连不上或很慢。
贝锐**蒲公英**（<https://pgy.oray.com>）是同类产品，国内节点：

- 免费版够个人用（设备数有限）
- Mac 装客户端、手机装 APP，**同一个账号**
- 之后用蒲公英分配的**虚拟 IP** 访问，用法与 §2 完全一样

**花生壳**（<https://hsk.oray.com>）是**内网穿透**而非组网 —— 它会把端口
**映射到公网**。若用它，**必须**加 `--password`（见 §5）。

---

## 4. 有公网 IP 时：路由器 IPSec VPN

登录 EG105G-P-L 后台（地址见机身标签或说明书），找到「VPN」→「IPSec」，
配置服务端；手机侧用**系统自带**的 VPN 客户端（iOS / Android 都支持 IPSec）。

> **具体配置项随固件版本而异，本文不给截图** —— 以你后台里实际看到的为准。
> 若 §0.1 测出没有公网 IP，这条路直接不通，走 §2 或 §3。

---

## 5. ⚠️ 无论走哪条路，都加一道密码

```bash
.venv/bin/python scripts/serve_dashboard.py --password fg:你的密码
```

- 浏览器会弹出账号密码框（HTTP Basic）
- 加 `--password` 后**所有路由**都要登录 —— 含 `/manifest.json`、图标、`/apk`
- 也可以用环境变量：

```bash
export FG_DASHBOARD_PASSWORD='fg:你的密码'
.venv/bin/python scripts/serve_dashboard.py
```

**隧道都加密了，为什么还要加**：**纵深防御**。隧道那层一旦配错（比如顺手
也做了端口映射）、或者设备丢了，还有这道门。

> ⚠️ Basic 认证在**纯 HTTP** 下是明文传输的 —— 所以它**必须**和隧道（或 HTTPS）
> 搭配使用，不能单独扛公网。

---

## 6. Mac 必须醒着

远程访问的前提是 Mac 在跑。macOS 默认会睡眠：

```bash
# 插电时永不睡眠
sudo pmset -c sleep 0

# 查看当前设置
pmset -g
```

> **⚠️ 合盖睡眠是硬伤** —— 笔记本**合上盖子**就没法远程了，
> `pmset` 也挡不住。真需要 7×24，得用**台式机 / Mac mini**，或让笔记本开盖放着。

## 7. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 手机装了 Tailscale 还是打不开 | 两端**不是同一个账号** | 检查登录账号是否一致 |
| 昨天能开、今天不行 | Mac 的 Tailscale IP 变了 | 重新 `tailscale ip -4` 确认 |
| 完全连不上 | Mac 睡眠 / 合盖了 | 见 §6 |
| 弹了账号密码框但进不去 | 密码格式不对 | 必须是 `用户名:密码`，别漏冒号 |
| 连上了但页面空白 | 服务没在跑 | Mac 上那个终端窗口还在不在 |
| 家里能开、外面不能 | 手机没开 Tailscale 开关 | 看 App 里的连接状态 |

---

## 附：为什么不用「端口映射 + DDNS」

1. **多半没有公网 IP**（§0.1），配了也不通
2. 就算通 —— 服务**无鉴权**时等于把持仓指令挂到公网；加 Basic 认证也只是
   **明文**（HTTP），需要再配 HTTPS 证书才安全
3. 暴露在公网会**持续被扫描**（Shodan 之类几小时内就能扫到）

⇒ 收益极低、风险极高。**用隧道。**
