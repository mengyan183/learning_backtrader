## 1. 结论先行

| 位置 | 结论 |
|---|---|
| 裁判裁决（stage_judge） | **值得试验**——输出形态天然匹配"三行裁决"结构，且带校准概率 |
| 深度归因打分 | 可作对照通道，价值中等 |
| 信号分级（🟢🟡⚪） | **不引入**——分级是确定性规则，不是概率决策 |
| 简报情绪/新闻节 | 不适用——需要文本生成，Jev 不给字符串 |
| 实盘买卖信号 | **红线不变**——Jev 输出永远标 🟡，除非回测证明改善 |

一句话：Jev 最匹配的位置是"裁判环节的概率化对照"，最不该碰的是"替代回测+pytest 的裁决"。

## 2. Jev 能力画像（官网事实，未独立验证）

- 类别：System One Model——非 LLM，不给字符串，只输出预定义 schema 的类型安全结构化值。
- 速度：端到端 70ms~500ms（LLM 3~329 秒，快 40~200 倍）。
- 成本：输入 $0.042/MTok，输出免费（官方自注：可能被补贴，长期价格预期下行）。
- 无幻觉：官方称"数学上不可能类型错误"（schema 匹配保证）；注意≠"决策正确"——概率需要校准验证。
- 概率：每个输出带校准置信度（高置信=高准确）。
- 基数：单次最高 255 选项；更高走两阶段（独立打分+显式选择）。
- 形态：并行采样，适合"智能 if 语句/分类/路由/打分/验证裁判"。
- 接入：早访问制（2026-09-15 开放），服务基于美西（与 NIM 同走 7890 海外代理通道）。

## 3. 本地裁判/信号链现状（改动前的基线）

1. 规则层（确定性）：档位边界、熔断、买卖观望线、信号分级——代码实现，无模型参与。
2. 模型层：
   - 情绪/新闻节：Hermes（GLM 云端）。
   - 深度归因 + 裁判裁决：NVIDIA NIM deepseek-v4.1-flash（海外走 7890 代理）。
   - 裁判输出契约：三行纯文本（评级:/理由:/风险:），`_validate_judge` 校验，不匹配则丢弃。
   - 历史教训：本地 qwen2.5-coder:3b 裁判任务倾向输出 tool_call JSON，已弃用本地模型。
3. 纪律层：回测 + pytest 是唯一裁判；LLM 永不判决；OOS 禁直接调参。

## 5. 风险与边界

1. **"无幻觉"≠"无错误"**：类型安全保证输出合法，不保证决策合理；概率校准需用真实样本验证，不能采信营销数字。
2. **早访问阶段**：官方明示"让开发者等 waitlist"；定价可能被补贴，长期不可假设永远免费。
3. **网络依赖**：美西服务 + 海外通道，与本机 NIM 同链路；公司电脑纪律（FG_STATIC_ONLY）下同样受限。
4. **双向裁判冲突**：Jev 与 NIM 裁判不一致时，以谁为准？必须先定"对照期"规则：Jev 只记录，不覆盖现有裁决。
5. **纪律写入**：任何引入都必须保留"回测+pytest 唯一裁判"条款；Jev 输出默认 🟡 研究参考。

- 不做的：任何把 Jev（或任何模型）放进"回测+pytest"裁决路径的改动。
