# M2.1 决策记录：组合回测层 A/B 对照（2026-10-11）

## 结论

**B 方案（内化）落地**：组合层**不引入 `bt`**，复用生产回测引擎
（`runner.run_single` + `FgStrategy` + `portfolio.next_position` + backtrader
成交/成本），组合 = 单标的策略日收益的**等权合成**（构造性一致，max|diff|=0）。

## A 方案（引入 `bt`）对照

- `bt`（MIT、纯 pandas）能简化「因子打分 → 目标权重 → 再平衡」表达；venv 未安装。
- **否决理由**（与「不引入 Qlib / QuantConnect / vn.py 全家桶」纪律同源）：
  1. **双引擎不一致**：`bt` 的成交/成本/执行约束与生产 `FgStrategy` 不同，
     组合结果与单标的口径不可比——「回测里的规则 ≠ 生产规则」的代价直接违反 §11 纪律；
  2. **黑箱裁判风险**：引入第二个交易引擎 = 引入第二个裁判口径，评审与归因成本上升；
  3. **零新依赖**：当前实现零新增 pip 依赖，单机维护面不扩大。
- 结论记录：**引入 bt = 否决；内化 = 采纳**（M2.1 验收「结论记录后决策」完成）。

## 为什么「等权合成」是诚实的组合层

- 三标的白名单（TQQQ/SOXL/UPRO）共享同一市场信号 `target_position`；
  组合层把 INITIAL_CASH **等权 1/3** 分给三标的（无参数先验），每标的独立跑
  生产同款策略（含执行约束 `next_position`、commission、slippage）。
- 组合日收益 ≡ Σ(1/3)·单标的日收益：**构造保证**，不是近似。
  交叉验证 = max|组合 - Σ(1/3)·腿| = **0**（脚本内断言）。
- 与 `evolution/baseline.json` 单标的口径逐一对齐（OOS）：
  TQQQ 28.07% = 0.280741 ✓；SOXL 64.68% = 0.646817 ✓；UPRO 19.57% = 0.195714 ✓。

## 组合层新增维度（单标的没有的）

- **组合级风险**：联合回撤 -26.07%（OOS） vs 等权 B0 -61.70% —— 风控显著优于买入持有；
- **相关性矩阵**（策略日收益）：TQQQ-SOXL 0.89 / TQQQ-UPRO 0.94 / SOXL-UPRO 0.82
  —— 三标的同信号驱动、高度相关 ⇒ 组合集中度风险高，分散化收益有限；
  未来若引入低相关标的（观察池）需按相关性重新评估权重。
