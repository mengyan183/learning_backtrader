# GOALS.md — 进化目标与红线

> 定位：本系统"自我进化"= 研究通道内生成可证伪假说 → 变体验证 → 证据提案 → 人工审批。
> LLM 是建议者，回测是裁判，人工是审批者。

## 目标
1. 系统自动发现"可证伪的改进假说"，并持续积累证据
2. 每个假说都有明确的不成立判据，证伪即成果
3. 生产路径（config.py / 核心信号 / 等价性守卫）在采纳前逐位不变

## 红线（违反即回滚）
1. LLM 永不直接写 config.py —— 参数变更必须走第 8 条流程提案
2. 永不绕过等价性守卫 —— 分析里的规则 ≠ 生产的规则
3. OOS 禁止调参 —— 样本外只有一次验收权
4. 证伪即成果 —— 反证不得静默丢弃，须入 LESSONS.md
5. 不自动上线 —— STAGE 闸门不变，采纳权永远在人工
